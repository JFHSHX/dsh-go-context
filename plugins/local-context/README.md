# dsh-go-context

dsh-context 的 dsh-go 原生上下文面板。

- 状态条：当前会话 tokens / 窗口 / 百分比
- 上下文洞察、用量总览、上下文演变、全部洞察四个面板
- 对话信息页「复制上下文报告」导出 Markdown

安装：

```sh
dsh plugin --profile web add dsh-go-context
```

要求：DSH >=0.2.1-rc.2、dsh-go 桥，以及宿主安装 dsh-context >=0.84。
