# dsh-go-context-activity

dsh-context 的 dsh-go 原生团队与活动面板。

- Agent 网络：成员、委派和最近消息
- 文件活动：读写、增删行和失败操作
- 命令执行：状态、耗时、输出大小和工具排行
- 对话信息页一键复制活动报告

```sh
dsh plugin --profile web add dsh-go-context-activity
```

要求：DSH >=0.2.1-rc.2、dsh-go 桥，以及宿主安装 dsh-context >=0.84。
